1. 任務說明：9 種白色粉末

食品實驗室的桌上出現 9 罐粉末：蔗糖、葡萄糖、果糖、阿斯巴甜（甜味劑）、咖啡因（提神飲料主角）、苯甲酸、己二烯酸鉀（防腐劑）、檸檬酸（酸味劑）、草酸（對照用有機酸）。它們長得一模一樣，但拉曼光譜一照——指紋立現。

不過儀器匯出資料時出了點狀況：同一份量測被存成三種橫軸格式，其中兩種不能直接當「拉曼位移」用。這堂課的目標：

🎯 救援術一：把「像素編號」橫軸換算回波數（複習 + 己二烯酸鉀實戰）
🎯 救援術二：把「散射光波長 (nm)」橫軸換算成波數（全新物理公式）
🎯 用 Python 與 R 各寫一次，並用 9 種樣品的資料互相驗證
🎯 最後通過 6 題闖關測驗檢查學習成效

3. 物理課：拉曼位移公式（救援術二的鑰匙）

雷射（波長 λ₀）打進樣品後，少數光子把能量留給分子振動再彈出來，波長變長成 λ。能量損失恰好等於分子振動的能量，用波數（cm⁻¹，波長的倒數）表示最方便：

拉曼位移 Δν̃ (cm⁻¹) = （ 1/λ₀ − 1/λ ）× 10⁷　　（λ₀、λ 都用 nm）

×10⁷ 是單位換算：1 nm = 10⁻⁷ cm，所以「1/nm」乘上 10⁷ 就變成「1/cm」。這個公式只適用波長變長的斯托克斯線（拉曼實驗最常用）。

動手試：拖動滑桿改變散射光波長 λ，看拉曼位移怎麼變（雷射固定 785.614 nm，原因見第 5 節）：λ₀ = 785.614 nm，λ = 820.1 nm

790 nm 1119 nm
536.1 cm⁻¹
這正是蔗糖最強峰的位置（實測 820.139 nm）！

為什麼 nm 檔不能直接用？同一個分子振動（例如 1649 cm⁻¹），換一支雷射，散射光波長就完全不同；但拉曼位移永遠不變。所以光譜學的「通用地址」是波數，不是波長。nm 檔只是「把地址寫成當地路標」，必須翻譯。

4. 救援術一：pixel → cm⁻¹（三次多項式）

原理與鑽石那一課相同：拿一份同儀器、同設定、波數已校正的檔案當「標準尺」，對 2048 個像素配一條三次曲線。這次用己二烯酸鉀示範——它三種格式都有，可以當場對答案。

rescue1_pixel.py 
# ===== 讀取標準尺：己二烯酸鉀的 wavenumber 檔 =====
import numpy as np
wn    = np.loadtxt("potasium_sorbate_200mW_1000ms_avg5_wavenumber_1.txt")[:, 0]
pixel = np.arange(len(wn))              # 0~2047
coef  = np.polyfit(pixel, wn, 3)        # 三次多項式，殘差 < 0.01 cm⁻¹

# ===== 救援己二烯酸鉀自己的 pixel 檔 =====
px   = np.loadtxt("potasium_sorbate_200mW_1000ms_avg5_pixel_1.txt")
chan = px[np.argmax(px[:, 1]), 0]      # 最強峰在通道 615
print(np.polyval(coef, chan))          # → 1649.2 cm⁻¹
rescue1_pixel.R 
wn    <- read.table("potasium_sorbate_200mW_1000ms_avg5_wavenumber_1.txt")$V1
naph_px <- data.frame(pixel = 0:(length(wn) - 1))
fit   <- lm(wn ~ poly(naph_px$pixel, 3, raw = TRUE))

px   <- read.table("potasium_sorbate_200mW_1000ms_avg5_pixel_1.txt")
chan <- px[which.max(px$V2), 1]                       # 615
predict(fit, data.frame(pixel = chan))               # → 1649.2 ✔

5. 救援術二：nm → cm⁻¹（先抓出雷射的真實波長）

nm 檔記錄的是「每個像素收到的光波長」。套用第 3 節公式就能翻譯成波數——但前提是知道雷射波長 λ₀。儀器標籤寫 785 nm，這是真的嗎？

偵探時間：用資料自己找出 λ₀

同一份己二烯酸鉀量測，wavenumber 檔給了正確位移 Δν̃，nm 檔給了波長 λ。把公式反過來用：

1/λ₀ = Δν̃ + 1/λ　→　λ₀ = 10⁷ ÷（ Δν̃ + 1/λ ）

2048 個像素各算一遍再平均——三種樣品都算，答案一致：

樣品反推的 λ₀
蔗糖785.6144 nm
葡萄糖785.6144 nm
己二烯酸鉀785.6144 nm

🔎 偵探結論：雷射標稱 785 nm，實際是 785.6144 nm（溫度、老化都會讓雷射微飄）。如果直接用 785.000 去換算，全譜圖會系統性偏移，最大誤差達 17 cm⁻¹——足夠把峰認錯！

實戰：翻譯蔗糖的 nm 檔

rescue2_nm.py 
# ===== 第 1 步：用「雙格式」樣品反推雷射真實波長 =====
import numpy as np
wn = np.loadtxt("glucose_200mW_1000ms_avg5_wavenumber_1.txt")[:, 0]
nm = np.loadtxt("glucose_200mW_1000ms_avg5_nm_1.txt")[:, 0]
L  = 1e7 / np.mean(wn + 1e7/nm)      # 785.6144 nm

# ===== 第 2 步：套公式翻譯蔗糖的 nm 檔 =====
suc   = np.loadtxt("sucrose_200mW_1000ms_avg5_nm_1.txt")
raman = 1e7/L - 1e7/suc[:, 0]        # 每個像素的拉曼位移！

# ===== 第 3 步：找最強峰並對答案 =====
i = np.argmax(suc[:, 1])
print(f"蔗糖最強峰 {raman[i]:.1f} cm⁻¹")   # 535.8
rescue2_nm.R 
wn <- read.table("glucose_200mW_1000ms_avg5_wavenumber_1.txt")$V1
nm <- read.table("glucose_200mW_1000ms_avg5_nm_1.txt")$V1
L  <- 1e7 / mean(wn + 1e7/nm)          # 785.6144 nm

suc   <- read.table("sucrose_200mW_1000ms_avg5_nm_1.txt")
raman <- 1e7/L - 1e7/suc$V1
i     <- which.max(suc$V2)
cat("蔗糖最強峰:", raman[i], "cm-1\n")  # 535.8

8. 重點整理

① 三種橫軸：波數（標準答案）、像素（需多項式校正曲線）、波長 nm（需拉曼位移公式）。

② 救援術一（pixel → cm⁻¹）：用同儀器已校正檔案配三次多項式。Python：np.polyfit + np.polyval；R：lm(y ~ poly(x,3,raw=TRUE)) + predict。

③ 救援術二（nm → cm⁻¹）：Δν̃ = (1/λ₀ − 1/λ)×10⁷。λ₀ 不能抄標籤——用「雙格式樣品」反推（本批資料實測 785.6144 nm，不是 785.000！）。

④ 驗證哲學：同一樣品的多種格式互相對答案（己二烯酸鉀 1649.2 = 1649.2），再加文獻峰抽查（苯甲酸 999 vs 1003 ✔）。永遠不要只靠一種證據。

⑤ 指紋資料庫：9 種食品添加物的主要峰位已整理成表——下次遇到白色粉末，先照譜、再對卡。
