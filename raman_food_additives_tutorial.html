3. 物理課：拉曼位移公式（救援術二的鑰匙）3. Physics lesson: the Raman-shift equation (the key to rescue method 2)

雷射（波長 λ₀）打進樣品後，少數光子把能量留給分子振動再彈出來，波長變長成 λ。能量損失恰好等於分子振動的能量，用波數（cm⁻¹，波長的倒數）表示最方便：After the laser (wavelength λ₀) enters the sample, a small fraction of photons gives energy to molecular vibrations and emerges again with a longer wavelength λ. The energy loss equals the molecular-vibration energy, and it is most convenient to express it as wavenumber (cm⁻¹, the reciprocal of wavelength):

拉曼位移 Δν̃ (cm⁻¹) = （ 1/λ₀ − 1/λ ）× 10⁷　　（λ₀、λ 都用 nm）Raman shift Δν̃ (cm⁻¹) = ( 1/λ₀ − 1/λ ) × 10⁷ (λ₀ and λ both use nm)

×10⁷ 是單位換算：1 nm = 10⁻⁷ cm，所以「1/nm」乘上 10⁷ 就變成「1/cm」。這個公式只適用波長變長的斯托克斯線（拉曼實驗最常用）。×10⁷ performs the unit conversion: 1 nm = 10⁻⁷ cm, so multiplying “1/nm” by 10⁷ gives “1/cm”. This equation applies only to the longer-wavelength Stokes line (the most commonly used case in Raman experiments).

為什麼 nm 檔不能直接用？同一個分子振動（例如 1649 cm⁻¹），換一支雷射，散射光波長就完全不同；但拉曼位移永遠不變。所以光譜學的「通用地址」是波數，不是波長。nm 檔只是「把地址寫成當地路標」，必須翻譯。Why can’t the nm file be used directly? The scattered-light wavelength changes completely when the laser changes, even for the same molecular vibration (for example, 1649 cm⁻¹); the Raman shift, however, never changes. That is why wavenumber—not wavelength—is spectroscopy’s “universal address”. The nm file is only a “local road sign” for the address and must be translated.

4. 救援術一：pixel → cm⁻¹（三次多項式）4. Rescue 1: pixel → cm⁻¹ (cubic polynomial)

原理與鑽石那一課相同：拿一份同儀器、同設定、波數已校正的檔案當「標準尺」，對 2048 個像素配一條三次曲線。這次用己二烯酸鉀示範——它三種格式都有，可以當場對答案。The principle is the same as in the diamond lesson: use a file from the same instrument and settings, with wavenumbers already calibrated as a "ruler," and fit a cubic curve to 2048 pixels. This example uses potassium sorbate; it has all three formats, so we can check the answer on the spot.

rescue1_pixel.py 
# ===== 讀取標準尺：己二烯酸鉀的 wavenumber 檔 ========== Read the reference ruler: potassium sorbate wavenumber file =====
import numpy as np
wn    = np.loadtxt("potasium_sorbate_200mW_1000ms_avg5_wavenumber_1.txt")[:, 0]
pixel = np.arange(len(wn))              # 0~2047
coef  = np.polyfit(pixel, wn, 3)        # 三次多項式，殘差 < 0.01 cm⁻¹Cubic polynomial; residual < 0.01 cm⁻¹

# ===== 救援己二烯酸鉀自己的 pixel 檔 ========== Recover the potassium sorbate pixel file =====
px   = np.loadtxt("potasium_sorbate_200mW_1000ms_avg5_pixel_1.txt")
chan = px[np.argmax(px[:, 1]), 0]      # 最強峰在通道 615Strongest peak at channel 615
print(np.polyval(coef, chan))          # → 1649.2 cm⁻¹
rescue1_pixel.R 
wn    <- read.table("potasium_sorbate_200mW_1000ms_avg5_wavenumber_1.txt")$V1
naph_px <- data.frame(pixel = 0:(length(wn) - 1))
fit   <- lm(wn ~ poly(naph_px$pixel, 3, raw = TRUE))

px   <- read.table("potasium_sorbate_200mW_1000ms_avg5_pixel_1.txt")
chan <- px[which.max(px$V2), 1]                       # 615
predict(fit, data.frame(pixel = chan))               # → 1649.2 ✔

5. 救援術二：nm → cm⁻¹（先抓出雷射的真實波長）5. Rescue 2: nm → cm⁻¹ (first find the laser's true wavelength)

nm 檔記錄的是「每個像素收到的光波長」。套用第 3 節公式就能翻譯成波數——但前提是知道雷射波長 λ₀。儀器標籤寫 785 nm，這是真的嗎？The nm file records "the wavelength of light received by each pixel." Apply the formula from Section 3 to translate it into wavenumber; but only if the laser wavelength λ₀ is known. The instrument label says 785 nm; is that true?

偵探時間：用資料自己找出 λ₀Detective work: find λ₀ from the data

同一份己二烯酸鉀量測，wavenumber 檔給了正確位移 Δν̃，nm 檔給了波長 λ。把公式反過來用：For the same potassium sorbate measurement, the wavenumber file gives the correct shift Δν̃, while the nm file gives the wavelength λ. Rearrange the formula:

1/λ₀ = Δν̃ + 1/λ　→　λ₀ = 10⁷ ÷（ Δν̃ + 1/λ ）1/λ₀ = Δν̃ + 1/λ → λ₀ = 10⁷ ÷ (Δν̃ + 1/λ)

2048 個像素各算一遍再平均——三種樣品都算，答案一致：Calculate it for all 2048 pixels and average the results—the answer is consistent across all three samples:

樣品Sample反推的 λ₀Inferred λ₀
蔗糖Sucrose785.6144 nm
葡萄糖Glucose785.6144 nm

🔎 偵探結論：雷射標稱 785 nm，實際是 785.6144 nm（溫度、老化都會讓雷射微飄）。如果直接用 785.000 去換算，全譜圖會系統性偏移，最大誤差達 17 cm⁻¹——足夠把峰認錯！🔎 Detective's conclusion: The laser is labeled 785 nm but is actually 785.6144 nm (temperature and aging can make the laser drift slightly). If you use 785.000 directly, the entire spectrum shifts systematically, with errors of up to 17 cm⁻¹—enough to misidentify a peak!

實戰：翻譯蔗糖的 nm 檔Hands-on: translate the sucrose nm file

rescue2_nm.py 
# ===== 第 1 步：用「雙格式」樣品反推雷射真實波長 ========== Step 1: infer the laser's true wavelength from a dual-format sample =====
import numpy as np
wn = np.loadtxt("glucose_200mW_1000ms_avg5_wavenumber_1.txt")[:, 0]
nm = np.loadtxt("glucose_200mW_1000ms_avg5_nm_1.txt")[:, 0]
L  = 1e7 / np.mean(wn + 1e7/nm)      # 785.6144 nm

# ===== 第 2 步：套公式翻譯蔗糖的 nm 檔 ========== Step 2: apply the formula to translate the sucrose nm file =====
suc   = np.loadtxt("sucrose_200mW_1000ms_avg5_nm_1.txt")
raman = 1e7/L - 1e7/suc[:, 0]        # 每個像素的拉曼位移！Raman shift for every pixel!

# ===== 第 3 步：找最強峰並對答案 ========== Step 3: find the strongest peak and check the answer =====
i = np.argmax(suc[:, 1])
print(f"蔗糖最強峰Sucrose strongest peak {raman[i]:.1f} cm⁻¹")   # 535.8

8. 重點整理8. Key takeaways

① 三種橫軸：波數（標準答案）、像素（需多項式校正曲線）、波長 nm（需拉曼位移公式）。① Three x-axes: wavenumber (the standard answer), pixel (requires a polynomial calibration curve), and wavelength nm (requires the Raman-shift equation).

② 救援術一（pixel → cm⁻¹）：用同儀器已校正檔案配三次多項式。Python：np.polyfit + np.polyval；R：lm(y ~ poly(x,3,raw=TRUE)) + predict。② Rescue 1 (pixel → cm⁻¹): Fit a cubic polynomial using a calibrated file from the same instrument. Python: np.polyfit + np.polyval; R: lm(y ~ poly(x,3,raw=TRUE)) + predict.

③ 救援術二（nm → cm⁻¹）：Δν̃ = (1/λ₀ − 1/λ)×10⁷。λ₀ 不能抄標籤——用「雙格式樣品」反推（本批資料實測 785.6144 nm，不是 785.000！）。③ Rescue 2 (nm → cm⁻¹): Δν̃ = (1/λ₀ − 1/λ)×10⁷. Do not copy λ₀ from the label; infer it using a “dual-format sample” (the measured value for this batch is 785.6144 nm, not 785.000!).

④ 驗證哲學：同一樣品的多種格式互相對答案（己二烯酸鉀 1649.2 = 1649.2），再加文獻峰抽查（苯甲酸 999 vs 1003 ✔）。永遠不要只靠一種證據。④ Validation philosophy: Cross-check multiple formats of the same sample (potassium sorbate 1649.2 = 1649.2), then spot-check literature peaks (benzoic acid 999 vs 1003 ✔). Never rely on only one type of evidence.

⑤ 指紋資料庫：9 種食品添加物的主要峰位已整理成表——下次遇到白色粉末，先照譜、再對卡。⑤ Fingerprint database: The main peak positions for 9 food additives are organized in a table; next time you encounter a white powder, read its spectrum first, then compare it with the card.
