2. 三分鐘認識拉曼光譜2. Three-minute introduction to Raman spectroscopy

把雷射打在樣品上，絕大多數光子以幾乎不變的能量散射（瑞利散射）；但極少數光子會和樣品的分子或晶格振動交換能量——這叫拉曼散射（Raman scattering）。入射光與散射光的能量差通常以拉曼位移（Raman shift，單位 cm⁻¹）表示，對應樣品允許的振動模態。Shine a laser on a sample: most photons scatter with almost no change in energy (Rayleigh scattering), but a very small number exchange energy with molecular or lattice vibrations in the sample—this is called Raman scattering. The energy difference between incident and scattered light is usually expressed as Raman shift (unit: cm⁻¹), corresponding to vibrational modes allowed by the sample.

所以：一組峰的位置、形狀與相對強度可形成分子或晶體的光譜指紋；定性時應比對整體圖樣與量測條件，而不是看到單一峰就直接定案。Therefore: the position, shape, and relative intensity of a set of peaks can form a spectral fingerprint of a molecule or crystal; for qualitative identification, compare the overall pattern and measurement conditions rather than making a definite identification from a single peak.

4. 解題發想：萘丸就是那把尺4. The idea: use the mothball as a ruler

5. 數學模型：多項式迴歸5. Mathematical model: polynomial regression

我們想找一條通過所有（像素, 波數）點的平滑曲線。最常用的選擇是多項式：We want a smooth curve that passes through all (pixel, wavenumber) points. The most common choice is a polynomial:

波數 ≈ a₀ + a₁·x + a₂·x² + a₃·x³ 　　（x = 像素編號）Wavenumber ≈ a₀ + a₁·x + a₂·x² + a₃·x³ (x = pixel index)

符號說明：x 是像素編號（無單位）；輸出是拉曼位移（cm⁻¹）；a₀ 是截距（cm⁻¹），a₁、a₂、a₃ 分別把 x、x²、x³ 換成 cm⁻¹ 的係數。這個公式只在本次參考資料涵蓋的像素範圍內使用，不應外插。Symbols: x is the pixel index (unitless); the output is Raman shift (cm⁻¹); a₀ is the intercept (cm⁻¹), while a₁, a₂, and a₃ are the coefficients that convert x, x², and x³ into cm⁻¹. Use this formula only within the pixel range covered by these reference data; do not extrapolate.

「迴歸」就是請電腦自動調整 a₀～a₃ 四個係數，讓曲線盡量貼近 2048 個資料點。多項式是常見的像素—波數轉換方法[2]，但幾次方要選多高必須依儀器與參考峰分布驗證。本資料的比較如下：“Regression” asks the computer to adjust the four coefficients a₀–a₃ automatically so that the curve stays as close as possible to 2048 data points. Polynomial regression is a common pixel-to-wavenumber conversion method[2], but the degree must be chosen and validated based on the instrument and the distribution of reference peaks. Here is the comparison for these data:

初學者心法：次數太低 → 曲線太硬，彎不過來（underfitting，欠擬合）；次數太高 → 曲線追著雜訊跑（overfitting，過度擬合）。本案例三次式的殘差很小，所以可作教學重建；正式校正還應把部分參考峰暫時留出，檢查模型能否預測沒參與擬合的峰。研究也顯示物理模型在參考峰範圍外可能比多項式可靠[4]。A beginner’s rule of thumb: too low a degree → the curve is too stiff and cannot bend enough (underfitting); too high a degree → the curve chases the noise (overfitting). The residual of the cubic model in this case is very small, so it works for this teaching reconstruction; formal calibration should also hold out some reference peaks and check whether the model predicts peaks not used in fitting. Research also shows that a physical model may be more reliable than a polynomial outside the reference-peak range[4].

6. Python 實作6. Python implementation

只需要一個套件 NumPy（安裝：pip install numpy）。整段程式只做三件事：讀檔 → 找公式 → 代入。You need only one package, NumPy (install with: pip install numpy). The whole script does three things: read the file → find the formula → substitute.

diamond_calibration.py 
# ===== 第 1 步：讀取萘丸資料（它有校正好的波數）========== Step 1: Read the naphthalene-mothball data (it has calibrated wavenumbers) =====
import numpy as np                          # 匯入數值計算工具箱，取名 npImport the numerical-computing toolbox and call it np

data = np.loadtxt("naphethelene_100mW_1000ms_avg5_1.txt")  # 讀兩欄文字檔 → 二維陣列Read the two-column text file → a two-dimensional array
wavenumber = data[:, 0]                     # 第 0 欄 = 波數（校正過的）Column 0 = wavenumber (calibrated)
pixel      = np.arange(len(wavenumber))    # 自己編號：0,1,2,…,2047Assign the indices ourselves: 0,1,2,…,2047

# ===== 第 2 步：找出「像素 → 波數」的公式 ========== Step 2: Find the “pixel → wavenumber” formula =====
coef = np.polyfit(pixel, wavenumber, 3)    # 三次多項式迴歸，回傳 4 個係數Fit a cubic polynomial and return 4 coefficients
print(coef)
# [ 1.40578532e-07 -8.87048888e-04  3.04828977e+00  7.73547341e+01 ]

# ===== 第 3 步：把公式套到鑽石檔案 ========== Step 3: Apply the formula to the diamond file =====
dia   = np.loadtxt("dimond_100mW_1000ms_avg5.txt")
chan  = dia[:, 0]                           # 鑽石的第 0 欄只是通道編號！Column 0 of the diamond data is only a channel index!
sig   = dia[:, 1]

peak_chan = chan[np.argmax(sig)]            # 最亮的位置 → 471Brightest position → 471
peak_wn   = np.polyval(coef, peak_chan)     # 代入公式 → 1331.0Substitute into the formula → 1331.0
print(f"鑽石最強峰：通道Diamond strongest peak: channel {peak_chan:.0f} ≈ {peak_wn:.1f} cm⁻¹")
# 鑽石最強峰：通道 471 ≈ 1331.0 cm⁻¹  ← 和文獻值 1332 只差 1！Diamond’s strongest peak: channel 471 ≈ 1331.0 cm⁻¹  ← only 1 away from the literature value 1332!
